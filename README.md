# Academic Outreach Portfolio

Warm cream academic portfolio + private outreach workspace.

## GitHub Pages update
Upload/replace `index.html` in the root of the `academic-outreach` repository and commit. GitHub Pages will redeploy automatically.

## Avatar
Open Home → Edit profile / avatar. The image is stored locally in the browser. Use **导出公开版（含头像）** and replace the repository `index.html` to make that avatar visible to public visitors.
